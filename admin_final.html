Вход в кабинет

Как получить токен (один раз, ~2 минуты)

GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
Repository access: Only select repositories → выбрать репозиторий сайта.
Permissions → Repository permissions → Contents: Read and write. Остальное не нужно.
Если задать пароль, токен сохранится на этом компьютере в зашифрованном виде (AES-256), и дальше для входа хватит одного пароля. Без пароля токен живёт только до закрытия вкладки.

🛍 Продажа принтов (Shopify)

Кнопка «Buy Print» появляется на сайте у конкретной картины, только если у неё заполнен товар Shopify (значок ✎ у строки картины ниже) — и один раз настроен сам сайт:

1. Shopify Admin → Settings → Apps and sales channels → Develop apps → создать приложение → Configure Storefront API scopes → включить нужные (read_products, unauthenticated_checkouts) → Install
2. Скопировать Storefront API access token
3. В файле assets/site.js найти строки SHOP_DOMAIN и STOREFRONT_TOKEN (в начале блока <script>) и вписать домен вида dianashirinova.myshopify.com и токен

Оригиналы работают иначе — по кнопке «Inquire About the Original» в лайтбоксе уходит письмо тебе, без Shopify.
